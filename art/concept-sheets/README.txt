Xtra Terram — Tower Art Concept Pack

Contents:
- Four generated visual concept sheets showing faction styles, tower tier progression, optional turret heads, creeps, projectiles/effects, and palette direction.
- The original art handoff brief.

Important:
These are concept/reference sheets, not production-ready individual sprite PNGs. The sheets include labels/grid elements and are not separated into the exact transparent 256x256/128x128 files described in the brief. For integration, each sprite still needs to be isolated, cleaned to true alpha transparency, cropped/anchored to spec, and named in public/sprites/<race>/<tower>/... before running `npm run sprites`.

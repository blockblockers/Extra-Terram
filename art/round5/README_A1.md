# Extra Terram Round 5 — Batch A1 (Rootkin tower stills)

This batch contains 16 individually cropped, RGBA tower stills for the four Rootkin families:
Whirlseed, Spirebirch, Sapwell, Elderwood. Filenames follow `public/sprites/rootkin/<family>/t1.png`, `t2.png`, `t3a.png`, `t3b.png`.

Important: these are first-pass generated/cropped production candidates, not hand-painted originals. They are normalized to 256x256 RGBA and bottom-aligned around the requested y=168 footprint anchor. Please visually review them in-game before treating them as final. No map art or animation strips are included in this batch.
